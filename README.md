# pampapad-pc

Programa de Windows del PampaPad, la botonera con la que se graba el canal Ingeniería en criollo. Vive en la bandeja, habla con OBS por obs-websocket y recibe las teclas de la consola por el cable USB.

Todavía no hay código. El repo existe desde antes para probar la actualización automática con una versión de prueba, que vive en la rama `prueba/velopack` y no se mergea.
